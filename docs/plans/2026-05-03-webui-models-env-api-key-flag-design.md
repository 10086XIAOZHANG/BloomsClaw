# WebUI Models Env API Key Flag Design

## Context

当前模型配置页仅支持编辑 `apiKey` 明文值，后端 `models` 配置中也只保存 `api_key`。

现在需要新增一个独立开关，用来标识某个模型的密钥是否应当从环境变量中读取，并把这个标识持久化到后端配置文件中。

## Decision

采用方案 A，增加独立布尔标识字段：

- 前端字段名为 `useEnvApiKey`
- 后端字段名为 `use_env_api_key`
- 页面中为每个模型新增一个 `Switch`
- 默认值为开启
- `API Key` 输入框仍保持现有编辑方式，不因开关状态改变语义

## Scope

本次包含：

- 前端模型类型扩展
- 模型配置页新增开关
- 前端请求与响应映射扩展
- 后端 DTO、校验、读写逻辑扩展
- 后端兼容旧配置，缺省时默认视为开启

本次不包含：

- 运行时根据该标识实际改用环境变量读取密钥
- 对 `API Key` 输入框做禁用或模式切换
- 前端自动化测试

## Notes

为了兼容历史配置，后端读取模型配置时如果缺少 `use_env_api_key`，则默认返回 `1`；前端也会对缺失字段回退为 `true`。
